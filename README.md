# EvoLab

Evolab is a project I made because i really admired how creatures evolve and how they interact with each other in order to do so, at first  i didn't think it would be anything big, maybe a few dots eating each other and reproducing but then i kinda got bored of it so decided to add different traits and mutations and it ended looks really cool. this project is built purely in python except for github page, i used pyscript(a bit of html) and minimal css( don't need it for the game ). AI helped me a little bit with the bugs and the sliders which was really hard to get working, but i finally managed to get it working. Overall this project was really really hard to make because i had to  spend a lot of time testing the project and adjusting each value so it would be perfect, thankfully it didn't end up pretty bad, i'm happy with the final result! 
to run the project run:
    python3 -m venv .venv
    .venv/bin/python -m ensurepip --upgrade
    .venv/bin/python -m pip install -r requirements.txt
    .venv/bin/python main.py

Controls: Space pauses. R replays the last minute. Clicking a creature shows its genome,
its energy and its family line in the panel on the right.YOu can also cahnge some settings using
The sliders whichchange how much food spawns, how aggressive the world selects for, the
speed, and the mutation rate.
